# SignBridge

Real-time sign language word recognition (100 ASL words, WLASL100) running entirely in
your browser: MediaPipe hand tracking + a Transformer exported to ONNX.

Allow camera access when prompted. If the camera is blocked inside the embedded frame,
open the Space directly via its `*.hf.space` URL.

Source code and training pipeline: see the GitHub repository.
